## Midterm Assignment

### 📌 Submission Instructions
To submit this midterm, you will use GitHub. Please follow these steps carefully:
1. **Create a new GitHub repository** specifically for this midterm.
2. **Task 1:** Provide the link to your customized GitHub profile. You can include this link at the top of your midterm repository's `README.md`.
3. **Task 2 & Task 3:** For each programming task, write your C++ code in a `main.cpp` file. Organize them in separate folders within your repository (e.g., `/Task2/main.cpp` and `/Task3/main.cpp`).
4. **Submit:** Turn in the link to your midterm GitHub repository.

### Task 1: Pimp Out Your GitHub Profile
**Objective:** Create a standout GitHub profile that acts as your professional coding portfolio.

*   **Instructions:** Use Markdown (`.md`) to create a profile README that highlights your skills, bio, and projects. 
*   **Resources:** Review the class presentation for insights on what makes a great GitHub page: [TTPR Github - Intro - Presentation.pptx](https://docs.google.com/presentation/d/1r6KmUe3AI2anmOQayaKYlWeLxAkD_f4J/edit)
*   **Grading:** You will be graded on the presentation, formatting, and the content you put on your page. Research and apply best practices for a professional developer profile!

### Task 2: Nested Loops - Christmas Tree Diamond
**Objective:** Demonstrate your understanding of nested loops to format terminal output.

*   **Instructions:** Based on the existing triangle code from our lab, use nested loops to create a C++ program that outputs a structure resembling a Christmas tree **diamond** (expanding on the triangle shape).
*   **Reference Code:** [lesson4-1/main.cpp](https://github.com/hhassan1230/MAC101-Course-Fall2026/blob/main/Labs/lesson4-1/main.cpp)
*   **Grading:** You will be graded on the correct implementation of nested loops and the accuracy of the final shape.

### Task 3: Choose Your Own Adventure (Inputs, Outputs & Conditionals)
**Objective:** Use `cin`, `cout`, and conditional statements (`if`/`else if`/`else`/`switch`) to guide a user through a logical flow.

*   **Instructions:** Create a small, text-based "Choose Your Own Adventure" game. 
    *   Use outputs (`cout`) to set the scene and ask the user what they want to do. 
    *   Use inputs (`cin`) to accept the user's choices (e.g., typing "left", "right", "1", or "2").
    *   Use conditionals (`if` / `else` / `switch`) to handle their choices and progress the story. 
*   **Example:** Think of a driving scenario where the adventure has you take inputs like "left" or "right" to navigate through obstacles or reach a destination.
*   **Scope:** Keep the adventure simple and short. 
*   **Grading:** You will be graded on your proper use of user input and how effectively your conditionals handle the adventure's logic and unexpected inputs.
